# Expense Tracker

A simple and responsive Expense Tracker built using HTML, CSS, and JavaScript. It allows users to add expenses, select expense categories, and keep track of their total spending through a clean and easy-to-use interface.

## Live Demo

[Expense Tracker](https://iabhinavchauhan.github.io/Expense-tracker/)

## Features

* Add new expenses
* Enter expense title and amount
* Select expense category
* Display total expenses

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

1. Enter the expense title.
2. Enter the amount.
3. Select the appropriate category.
4. Add the expense.
5. The expense is added dynamically and the total amount is updated.
